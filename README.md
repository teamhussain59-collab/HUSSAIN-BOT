
# HUSSAIN-BOT (Roman Urdu guide)
1. Railway par New Project > Deploy from GitHub repo > HUSSAIN-BOT select karo.
2. Variables mein OWNER_NUMBER set karo (apna number, country code ke saath, + ke bina, jaise 923XXXXXXXXX).
3. Deploy logs mein "Pairing code" dikhega.
4. WhatsApp > Linked devices > Link with phone number se wo code daalo.
5. "Bot connected." aane ke baad apne aap ko .ping bhejo.
